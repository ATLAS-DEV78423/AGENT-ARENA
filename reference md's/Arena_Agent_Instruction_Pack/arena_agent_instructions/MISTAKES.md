# Arena Mistake Log

This is a deposit store, not an always-on instruction file.

## Entry format

### YYYY-MM-DD — Short title

**Agent:** A | B

**What happened:**  
Describe the failure.

**Root cause:**  
Identify the actual cause, not the symptom.

**Prevention:**  
State the smallest durable prevention.

**Evidence:**  
Identify the test, transcript event, or reproducible observation.

**Graduation candidate:** yes | no

## Rule graduation

A maintainer or designated auditor reviews repeated mistakes.

A pattern may graduate into a hard rule only when it is recurring, material, and general enough to justify permanent context.

Do not automatically promote one-off mistakes into core instructions.

Keep graduated rules short and actionable.
